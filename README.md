# ClearGive Frontend


**ClearGive: A Web-Based Donation and Community Assistance Management System**

## Tech used
- React + Vite
- React Router
- Lucide React (UI icons)
- Plain CSS for the layout and responsive design

## Pages included
- Landing page
- Login
- Registration
- Donor Dashboard
- Donation Drives
- My Donations

## Run the project

1. Install Node.js.
2. Extract/open this folder in VS Code.
3. Open the terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown by Vite, usually:
`http://localhost:5173`

This is a frontend prototype. Login, registration, and donation recording currently use sample/mock data and are ready to connect to the Node.js/Express backend later.
